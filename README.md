# VPd05 — миникошелёк путешественника (Telegram)

Telegram-бот на Python (`pyTelegramBotAPI`): создаёт путешествия, хранит баланс в двух валютах, учитывает расходы и считает курс через реальный API CurrencyLayer.

## Возможности

- создание путешествия (страна отправления → страна назначения)
- получение курса через API и подтверждение / ручной ввод курса
- стартовый баланс: сумма в домашней валюте конвертируется в валюту назначения
- несколько путешествий на пользователя, переключение между ними
- число в чате = расход в валюте пребывания + подтверждение inline-кнопками
- баланс и история расходов
- inline-меню и слэш-команды

## Структура

| Файл | Назначение |
|------|------------|
| `bot.py` | Telegram-бот |
| `current_api.py` | запросы к API `/convert` |
| `database.py` | SQLite (`traveler_wallet.db`) |
| `countries.py` | страна → код валюты |
| `config.py` | загрузка `.env` |
| `requirements.txt` | зависимости |

## API

Используется endpoint:

```text
https://api.currencylayer.com/convert
```

`https://api.exchangerate.host/convert` для этого ключа не подходит (редирект на HTML-документацию).  
При создании поездки бот делает **один** запрос к API (курс); стартовая сумма считается локально.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Настройка

Создай файл `.env` в корне проекта (можно скопировать `.env.example`):

```env
TELEGRAM_TOKEN=токен_от_BotFather
ACCESS_KEY=ваш_ключ_CurrencyLayer
```

## Запуск

```powershell
.\.venv\Scripts\Activate.ps1
python bot.py
```

В Telegram открой бота и отправь `/start`.

## Меню и команды

**Inline-меню**

- Создать новое путешествие  
- Мои путешествия  
- Баланс  
- История расходов  
- Изменить курс  

**Команды**

| Команда | Действие |
|---------|----------|
| `/start`, `/menu` | главное меню |
| `/newtrip` | новое путешествие |
| `/switch` | список / переключение поездок |
| `/balance` | текущий баланс |
| `/history` | история расходов |
| `/setrate` | изменить курс вручную |

## Как пользоваться

1. Создай путешествие: страна отправления → страна назначения.  
2. Подтверди курс API или введи свой.  
3. Укажи начальную сумму в домашней валюте.  
4. Пиши расходы числом (например `100`) — бот пересчитает в домашнюю валюту и спросит, учитывать ли трату.  
5. Баланс всегда показывается в двух валютах, например:  
   `Остаток: 2400 CNY = 30 720 RUB`.

## Замечания

- данные пользователей хранятся локально в SQLite, у каждого свой набор путешествий;
- при ошибке `429 Too Many Requests` исчерпан лимит запросов тарифа API — подождите или обновите план;
- список поддерживаемых стран см. в `countries.py`.
